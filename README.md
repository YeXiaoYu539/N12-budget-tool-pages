# N12 科研经费测算工具

基于财防〔2019〕12号文金额规则的纯浏览器测算工具。

- 支持固定费用、合规重算、外购成品费与项目历史保存
- 点击“下载 Excel 测算表”下载预算及合规校验工作表
- 编制说明支持独立保存、查询、修改、另存及预算快照载入
- 材料与专用费按数量单价测算，外协费填写总价
- 事务费按金额、比例、广州出发城市及已确认价格生成可调整方案
- 燃动费按设备功率和用电时数、折旧费按原值和折旧率、管理费按政策基数详细测算
- 基础设备、资产与费用标准可在本机保存复用；旧版费用池公摊保留
- 项目资料与历史记录保存在本机，不上传服务器
- 本仓库仅包含静态编译文件，不包含单位内部原始财务数据或原始参考文档
